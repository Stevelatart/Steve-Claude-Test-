Methodology. Delivery KPIs (impressions, clicks, CTR, conversions), campaign, supply-source and site figures are taken from the Inventory report — each impression is counted once against the site it served on, so these are true delivery totals. The Audience segment report is used only for relative audience performance: because a single impression can match many segments at once, segment-level impression counts overlap and are not summed into delivery totals — they rank which audiences engage and convert, not how much was delivered.

Conversions are off-Amazon (pixel) actions. CTR = clicks ÷ impressions. All currency USD. Prepared by Brandography.
